# NSF MARVLS Project Website

GitHub Pages-ready static website for Siena University's NSF-supported MARVLS magnetism project.

## Pages
- `index.html` — Home
- `project.html` — Project overview
- `lessons.html` — Magnetism teaching materials
- `research.html` — Publications and local PDF downloads
- `gallery.html` — Student-photo and app-screenshot placeholders
- `team.html` — Project team

## Publish on GitHub Pages
1. Create a new GitHub repository.
2. Upload all files and folders in this directory to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. GitHub will provide the public Pages URL after deployment.

## Updating images
Replace or add files in `assets/images/`. Then edit `gallery.html` or other page image paths as needed.

## Notes
- Siena logos supplied by the project owner are included in `assets/images/`.
- Publication PDFs are stored in `assets/papers/`.
- The complete magnetism lesson packet is stored in `assets/lessons/`.
- The NSF acknowledgment and disclaimer are included in the footer of every page.
